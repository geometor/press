geometor.press.portraits.render_medallion_coin_svg(layers: dict[str, list[dict[str, Any]]], theme: str = 'adaptive') → str¶

Render a square transparent-exterior circular medallion coin SVG.

Centers the canonical medallion (MED_CX=0, MED_CY=-8, RIM_R=95.2) inside a 1:1 viewBox="-100 -108 200 200" with transparent exterior corners so it displays cleanly as a site logo, hero emblem, or collection thumbnail.

geometor.press.portraits.arc_through(p1: tuple[float, float], p2: tuple[float, float], sagitta: float) → tuple[float, float, float, float, float]¶

Compute circular arc (cx, cy, r, a1, a2) from p1 to p2 with signed sagitta.

Positive sagitta bows to the left of directed segment p1 -> p2 in SVG coordinates (x right, y down); negative sagitta bows to the right.

geometor.press.portraits.clip_arc_to_medallion(cx: float, cy: float, r: float, a1: float, a2: float, margin: float = 0.0) → list[tuple[float, float]]¶

Clip a circular arc (cx, cy, r, a1..a2) to stay strictly inside the medallion.

Returns a list of (start_deg, end_deg) sub-arc intervals whose points all lie within radius MED_R + margin of (MED_CX, MED_CY).
