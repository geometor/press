geometor.press.coffee_table¶

Coffee Table Book & Print PDF generator for GEOMETOR Press.

Produces facing-page spread PDFs (verso: enunciation, steps, proof, and machine-verified symbolic certificate; recto: full-bleed vector SVG plate) using WeasyPrint CSS Paged Media.
